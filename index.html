docxlike 在线转换

把 Word 文档转换成以最新版 docxlike 排版的 LaTeX 工程。 转换在浏览器本地完成，文件不会上传到服务器。

浏览器内 WASM 转换 ZIP 内含运行文件 可选 TeX Live 替代字体

拖入 .docx 文件

或点击选择文件

仅支持 DOCX。旧版 .doc 请先在 Word 中另存为 .docx。

字体处理
首次转换需要加载约 12 MB 的转换引擎。
  1. 加载转换引擎
  2. 读取 docxlike 运行文件
  3. 解析 DOCX 并生成 LaTeX
  4. 打包 ZIP

转换完成

下载 ZIP

解压后得到 main.tex、图片目录和 docxlike.sty、docxlike.lua。 在 Overleaf 中上传整个文件夹，并把编译器设为 LuaLaTeX。

转换报告（降级、占位与编程路径提示）

    说明

    • 字体：默认保留 Word 里的原字体名，不做替换；本机编译需要安装这些字体。若要直接在 Overleaf 编译，请选择“TeX Live 替代字体”，这时会把常用字体映射到 TeX Live 自带字体，字形细节会有差别。
    • 保真度：转换以版式对齐为目标，保留段落、字体、间距、表格、图片、脚注、域和公式等的可见内容。转换器不能表达的对象会列在“转换报告”中，并以占位或降级方式处理；“编程路径”条目表示改用底层接口写入，内容仍然保留。
    • 隐私：文件只在当前浏览器的 WASM 沙箱内解析，不发送到任何服务器。
    • 限制：不支持旧版二进制 .doc；不解析文档内容语义；不替代人工检查分页与断行。

    运行时 docxlike 0.1.0
